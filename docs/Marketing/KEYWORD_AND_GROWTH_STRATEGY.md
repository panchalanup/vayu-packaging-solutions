## 0. Executive summary

**What the research says**
1. The strongest search demand around boxes is *tool-shaped*: "volumetric weight calculator", "CBM calculator", "box size calculator", "box dieline template". Courier aggregators and freight sites own the first two with generic tools. None connects the answer to an actual box you can buy. We can.
2. Free box-design competitors (Pacdora, Packhelp Toolbox, GoVisually, Die Cut Templates) are global, priced in foreign currency or upsell paid plans, and have no Indian product templates (mango carton, mithai, saree, tiffin) and no ply/BF/GSM language. Canva is weak for dielines.
3. Indian manufacturer web presence is mostly IndiaMART/GlobalLinker listings with "price on request". A site that explains, sizes and estimates openly is rare. Opening this up (as ranges, labelled indicative) is a trust edge.
4. Fresh, checkable commercial topics exist: the 2025 GST rate change on corrugated boxes (reported 12% to 5% from 22 Sep 2025; input paper raised to 18%) is a "freshness" query with thin quality answers (`VERIFY-LATER[MKT-03]`).
5. We already have 36 articles and 18 style landing pages. The gap is not tool explanation. It is **problem-first, seller-first and number-first** content (shipping weight, marketplace packing, size charts, price/MOQ/GST) plus **link-magnet calculators**.

**Top 5 opportunities (ranked by expected return per hour)**
| # | Opportunity | Why |
|---|---|---|
| 1 | Volumetric weight + box size calculators with hand-off to the designer | Highest demand, clear intent, naturally linkable, every result ends in "design a smaller box" |
| 2 | Size-chart articles (mailer, cake, shoe, mithai, standard carton) where every table row opens that size in 3D | Long-tail "size for X" queries, high conversion, uses existing presets |
| 3 | Marketplace seller content (Amazon/Flipkart/Meesho, RTO damage, fragile packing) | Large audience of small buyers, community channels for distribution |
| 4 | Manufacturer/wholesaler partnership using presentation mode and embed | Low-volume but multiplies reach; each partner demos our tool to their customers |
| 5 | Local + commercial pages (Ahmedabad "how to choose", how to order, MOQ, GST, price examples) plus Google Business Profile | Closest to purchase; low-to-medium competition on long-tail |

### 3.3 Two-hour validation routine (do before writing each batch)
1. Google Keyword Planner (free account): paste each cluster's head terms, location India, note monthly range.
2. Google Trends India: compare 3 phrasings per topic (e.g. "volumetric weight calculator" vs "volumetric weight formula").
3. Search each target phrase in an incognito India-region window; screenshot top 10 and PAA. If top 10 is all IndiaMART/directories, our long-tail article can win; if top 10 is giant brands with tools, win via the calculator plus the box angle instead.
4. Search Console (once live): sort Queries by impressions where position is 8 to 30; those are the cheapest wins.
5. Record real volumes in a sheet and replace the L/M/H guesses in this document. `VERIFY-LATER[MKT-08]`

## (e) Six free calculator pages (client-side only)

Routes are suggestions (`/tools/<slug>`). No data leaves the browser; nothing is stored; no sign-up. Every calculator has: result card, "Copy result", "Share on WhatsApp", unit toggle (mm/cm/in), a short formula note, a disclaimer line, and the hand-off buttons below. Use `WebApplication`/`SoftwareApplication` plus `FAQPage` schema (helpers exist). Write the 40-to-60-word answer and the formula as visible text above the fold.

**Hand-off URL conventions**
- Designer: `/box-designer?style=<style>&l=<cm>&w=<cm>&h=<cm>&ply=<3-ply|5-ply|7-ply>&fl=<flutes>` (cm, per `landingPreset.ts`).
- Quote: `/quote?l=&w=&h=&ply=&qty=&src=tool.<slug>` (`/quote` ranges are 10 to 5000; confirm unit, likely mm `VERIFY-LATER[MKT-07]`). `src` allows only lowercase letters, digits, dot, hyphen, max 60 chars (no underscores).

### Tool 1: Volumetric weight calculator
| Item | Spec |
|---|---|
| Route / keyword | `/tools/volumetric-weight-calculator`; "volumetric weight calculator", "volumetric weight calculator India", "dimensional weight calculator" |
| Inputs | L, B, H (unit toggle); actual weight (kg or g); divisor (5000 default, 4000, 6000, custom); units per shipment; optional: your courier rate per kg (user enters) |
| Outputs | Volumetric kg = L x B x H (cm) / divisor; chargeable kg = max(actual, volumetric); which one wins; optional cost; "box volume you could shrink to before volumetric equals actual" ; "what a 10/20/30% smaller box saves" |
| Test vector | 30 x 20 x 15 cm: 1.8 kg at 5000, 2.25 kg at 4000 |
| Hand-off | "Design a box at the target size" -> designer; "Get a quote for this size" -> `/quote?src=tool.volumetric` |
| Notes | Show "Divisor varies by courier and service; check your rate card" `VERIFY-LATER[MKT-04]`; courier-specific rules such as flyer or 1 kg rules are not modelled |

### Tool 2: CBM and container/pallet loading calculator
| Item | Spec |
|---|---|
| Route / keyword | `/tools/cbm-calculator`; "cbm calculator", "container loading calculator", "how many cartons in 20ft container" |
| Inputs | Carton L, B, H; quantity; gross weight per carton; container (20ft, 40ft, 40ft HC) with editable usable-volume % (default 85%) and payload limit; pallet size (1200x1000 default, 1200x800, custom), pallet height limit |
| Outputs | CBM per carton and total; cartons per layer (best of orientation tries), layers, cartons per pallet; pallets per container; cartons per container by volume and by weight; limiting factor; fill % |

### Tool 4: Box strength (BCT) and stacking estimator
| Item | Spec |
|---|---|
| Route / keyword | `/tools/box-strength-calculator`; "box compression strength calculator", "McKee formula calculator", "how many boxes can I stack" |
| Inputs | Box inside L, B (H optional); board ECT (kN/m or lb/in) from presets or manual; board caliper (mm); stack height or load per box; safety factor (3 to 5, default 4); toggles: vents, hand holes, humid storage |
| Formula | Simplified McKee: BCT(lbf) = 5.87 x ECT(lb/in) x sqrt(caliper(in) x perimeter(in)); 1 kN/m = 5.71 lb/in. Test vector: ECT 32, caliper 0.125 in, perimeter 56 in -> about 497 lbf. | Outputs | Estimated BCT (kgf), allowable load, max stack height, plain-language verdict, "move to 5-ply" suggestion |
| Notes | Always state "indicative only; the simplified McKee formula is a quick estimate, not a rating; confirm with a lab test" (published guidance says the same) |
| Hand-off | "See ply options in 3D" -> designer with ply; quote with `src=tool.strength` |

## (i) Risks and claims to avoid

| Risk | Rule |
|---|---|
| Fake or unsourced social proof | No invented reviews, testimonials, logos, "trusted by" claims. Ask real customers for real reviews; show only what exists |
| Certificates and standards | No ISO, BIS, FSC, food-grade or similar claim until a document exists `VERIFY-LATER[CERT-01]`. For "food-grade" language, state exactly what is verified |
| Stats | Do not use "5M+ boxes", "250+ businesses", "5+ years" in outreach until verified (`VERIFY-LATER[FACT-01..04]`); never "India's best/No. 1" |
| Prices | Estimate is "indicative", not a quote; never publish a price list or "from Rs X" unless the rate is current and approved; every price example flagged `VERIFY-LATER` |
| Manufacturer vs supplier | Site text says boxes are made to order or sourced from vetted mills. Do not call ourselves a "factory" or claim machinery unless true (`VERIFY-LATER[MKT-01]`); use "manufacturer/supplier" wording only once decided |
| Promises | MOQ, 48-hour dispatch, sample policy, reply SLA are placeholders (`FACT-07, 08, 13, 19`); state their scope or leave out |
| Calculator accuracy | Disclaimers on every tool: courier divisors vary by courier and service; McKee is a simplified estimate, not a rating; container volumes are nominal; GST rates change |
| Legal/tax content | GST, HSN, export rules: cite source and date, link to CBIC or relevant authority, "not tax advice"; update when rules change |
| Competitor claims | Compare only what we verified; no screenshots of competitors without permission; no negative claims. Brand-name keywords ("Pacdora alternative") only in an honest comparison `VERIFY-LATER[MKT-11]` |
| Images | No AI-generated images. SVG illustrations and credited open-licence photos only (see `/image-credits`) |
| Messaging consent | WhatsApp broadcast to opted-in contacts only, with opt-out; cold email relevant and minimal with opt-out; follow platform rules `VERIFY-LATER[MKT-12, MKT-16]` |
| Data privacy | Calculators store nothing; lead forms carry a consent line; no personal data in analytics events |
| Community spam | Quora, Reddit and groups ban self-promotion; disclose affiliation, answer first, link rarely, ask admins before posting `VERIFY-LATER[MKT-14]` |
| Thin or duplicate SEO | No doorway city pages, no keyword stuffing, no near-duplicate articles; one owner page per keyword (guardrails in section b); set canonicals on tool and article variants |
| Buying links | No paid link schemes; earn links via tools and real partnerships (also stated in `BACKLINKS_STRATEGY.md`) |
| Domain change | Moving off `vercel.app` needs full 301 map, sitemap and Search Console property update `VERIFY-LATER[MKT-02]` |
| Seasonal dates | Festival and expo dates change yearly; verify before publishing `VERIFY-LATER[MKT-09]` |
| Over-promising strength | Never say a box "will hold X kg". Say "estimated" and advise a test for critical loads |
